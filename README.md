## 📌 Kernpunkte im Ueberblick

1. **0% MwSt. auf der Rechnung:** Google Ireland berechnet keine deutsche Umsatzsteuer, da die Umkehrung der Steuerschuldnerschaft greift.
2. **Konto SKR 03:** Konto 3123 (Sonstige Leistungen EU 19% VSt / USt)
3. **Konto SKR 04:** Konto 5923 (Leistungen nach Paragraph 13b UStG)
4. **Voraussetzung:** Gueltige europaeische USt-IdNr. muss in den Google Ads Zahlungsdaten hinterlegt sein.
